# SafeNestT Client Roadmap

## Phase 1 — Foundation

- Repository and documentation
- React/TypeScript client shell
- FastAPI service shell
- Environment configuration
- Health endpoint
- CI and test baseline

## Phase 2 — User accounts

- Registration/login
- Session handling
- Account settings
- Subscription/access state
- User security controls

## Phase 3 — Scam and fraud cases

- Report a scam
- Case creation and editing
- Case dashboard
- Case status and timeline
- Evidence intake
- Secure document handling

## Phase 4 — AI investigator

- Investigation job API
- Evidence normalization
- SafeNestT AI engine adapter
- Structured findings
- Investigation progress
- Human/investigator review states

## Phase 5 — Reports and recovery

- Case report generation
- Evidence index
- Export/download
- Recovery guidance
- Official reporting resources
- User notifications

## Phase 6 — Production

- Security review
- RLS/authorization verification
- Dependency audits
- End-to-end tests
- Observability
- Production deployment
- Backup/restore validation

## Definition of done

A phase is complete only after implementation, automated tests, security checks, and a real environment verification appropriate to that phase have passed.
